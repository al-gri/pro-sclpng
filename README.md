# ProScalping Radar

Криптовалютный скринер для Bitget. Первая версия — recorder, replay и shadow-алерты; без выставления ордеров.

## Состояние

Репозиторий инициализирован 2026-10-05. Исполняемый код, CI и торговые сигналы ещё не реализованы.

Стартовые документы и задания будут предложены отдельным pull request. Их слияние в `main` означает принятие базового плана владельцем проекта.

## Границы доступа

Работать только с `al-gri/pro-sclpng`. Не просматривать и не изменять другие репозитории.

Репозиторий публичный: не загружать ключи, приватную переписку, полные тексты платного курса, персональные данные или сырые рыночные архивы.

## Инициализация

Этот минимальный коммит создаёт базовую ветку для первого PR. Все последующие изменения предлагаются через отдельные ветки и PR; слияние выполняет владелец проекта.
