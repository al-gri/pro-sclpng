identity/generation/deadline; the script supplies observations only. Text

progress leaves an active Timeout's original CloseNotReady until a permitted
stage. Local stop uses existing same-authority mandatory Close and reclaim/
dispatch, without inventing received Disconnected. Drop is not receipt or
